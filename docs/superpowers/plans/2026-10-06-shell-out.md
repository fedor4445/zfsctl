# Shell-Out to a Host Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pressing `!` suspends the TUI, opens an interactive shell on the selected host (an unprivileged `ssh -t` login for remote hosts, `$SHELL` locally), and restores and refreshes the TUI when the shell exits.

**Architecture:** `handle_key` only sets `app.pending_shell` (the existing `pending_new_hosts` pattern); the event loop, which owns the terminal, drains it: leaves raw mode and the alternate screen, runs the child with inherited stdio, then restores everything. A new `src/ui/shell.rs` holds the pure command builder, the exit-status classifier and a SIGINT/SIGQUIT guard. `Host` gains `ssh_target` so the builder knows where to connect.

**Tech Stack:** Rust 2021, ratatui 0.29, crossterm 0.28, `nix` 0.29 (dev-dependency feature `signal`, for a test only), new dependency `signal-hook` 0.3.

**Spec:** `docs/superpowers/specs/2026-10-06-shell-out-design.md`

## Global Constraints

- The crate has `unsafe_code = "forbid"`; no `unsafe` anywhere, which is why the signal guard uses `signal-hook`.
- Remote shells run as the **unprivileged** user named in `ssh_target`: `ssh -t -- <ssh_target>`, never `sudo -i`, never `BatchMode`.
- The `--` goes before the target so a target starting with `-` cannot be read as an ssh option.
- `signal-hook` is the **only** new runtime dependency.
- Key is `!`. It does nothing while a modal or picker is open, or when there are no hosts.
- Clippy pedantic is on (`indexing_slicing`, `unwrap_used` are warnings): new non-test code must be clean under `cargo clippy --all-targets`.
- Baseline before starting: `cargo test` reports 715 passed.

## Review Focus

- `$SHELL` set but **empty** (or unset) must fall back to `/bin/sh`, not try to spawn an empty program. Pinned in Task 2.
- A **local** shell that exits with status 255 (`exit 255`) is a normal exit, not a "connection failed" error; only `ssh` uses 255 that way. Pinned in Task 2.
- **Ctrl-C inside the shell must not kill zfsctl**, and the default SIGINT behavior must be active again afterwards. Pinned in Task 2 (flag test) and Task 4 (live).
- A shell that **fails to spawn** must still leave the terminal back in raw mode on the alternate screen. Pinned structurally in Task 4 (resume always runs) and in Task 2 (spawn failure maps to `SpawnFailed`).
- `!` with **no hosts**, or while a **modal** is open, must be inert and must not be advertised in the hint bar. Pinned in Task 3.
- A refresh after a **failed** shell would wipe the error from the status line; only a finished shell refreshes. Pinned in Task 4.

```rust
//! Opening an interactive shell on a host from the TUI.
//!
//! The pure parts (building the command, classifying the exit) are separate
//! from the part that touches the terminal, which lives in the event loop.

use signal_hook::consts::{SIGINT, SIGQUIT};
use std::process::Command;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;

/// How the shell session ended.
#[derive(Debug, PartialEq, Eq)]
pub enum ShellOutcome {
    /// The shell ran and exited. Its own exit status is deliberately not an error.
    Finished,
    /// `ssh` could not connect or authenticate (it exits 255 for that).
    ConnectFailed,
    /// The program could not be started at all.
    SpawnFailed(String),
}

/// The command for a shell on a host: `ssh -t -- <target>` for a remote one
/// (an interactive login as that unprivileged user; no `BatchMode`, so a
/// password or passphrase prompt works; `--` keeps a target that looks like
/// an option from being read as one), or the user's `$SHELL` locally.
/// `shell_env` is the value of `$SHELL`, passed in so this stays pure.
pub fn shell_command(ssh_target: Option<&str>, shell_env: Option<&str>) -> Command {
    match ssh_target {
        Some(target) => {
            let mut c = Command::new("ssh");
            c.args(["-t", "--", target]);
            c
        }
        None => Command::new(shell_env.filter(|s| !s.is_empty()).unwrap_or("/bin/sh")),
    }
}

fn classify(exit_code: Option<i32>, remote: bool) -> ShellOutcome {
    if remote && exit_code == Some(255) {
        ShellOutcome::ConnectFailed
    } else {
        ShellOutcome::Finished
    }
}

/// While a shell runs the terminal is out of raw mode, so Ctrl-C is a real
/// SIGINT sent to the whole foreground process group, zfsctl included. This
/// swallows SIGINT/SIGQUIT only while a [`SignalSuspend`] is alive and keeps
/// the default action (terminate) the rest of the time.
pub struct ShellSignals {
    default_active: Arc<AtomicBool>,
}

impl ShellSignals {
    pub fn install() -> std::io::Result<Self> {
        let default_active = Arc::new(AtomicBool::new(true));
        for signal in [SIGINT, SIGQUIT] {
            signal_hook::flag::register_conditional_default(signal, Arc::clone(&default_active))?;
        }
        Ok(ShellSignals { default_active })
    }

    /// Ignores SIGINT/SIGQUIT until the returned guard is dropped.
    pub fn suspend(&self) -> SignalSuspend<'_> {
        self.default_active.store(false, Ordering::SeqCst);
        SignalSuspend { signals: self }
    }
}

pub struct SignalSuspend<'a> {
    signals: &'a ShellSignals,
}

impl Drop for SignalSuspend<'_> {
    fn drop(&mut self) {
        self.signals.default_active.store(true, Ordering::SeqCst);
    }
}

fn run_command(mut command: Command, remote: bool, signals: &ShellSignals) -> ShellOutcome {
    let _guard = signals.suspend();
    match command.status() {
        Ok(status) => classify(status.code(), remote),
        Err(e) => ShellOutcome::SpawnFailed(e.to_string()),
    }
}

/// Prints a one-line banner and runs the shell with inherited stdio until it
/// exits. The caller must already have left raw mode and the alternate screen.
pub fn run_shell(host_name: &str, ssh_target: Option<&str>, signals: &ShellSignals) -> ShellOutcome {
    println!("zfsctl: shell on {host_name} — exit to return");
    let command = shell_command(ssh_target, std::env::var("SHELL").ok().as_deref());
    run_command(command, ssh_target.is_some(), signals)
}
```

```rust
/// Leaves the TUI, runs a shell on the host, and puts the TUI back. The
/// terminal is restored even when the shell could not be started, so a
/// failure here can never strand the operator in a half-set-up terminal.
fn run_shell_session(
    terminal: &mut Terminal<CrosstermBackend<std::io::Stdout>>,
    host_name: &str,
    ssh_target: Option<&str>,
    signals: &shell::ShellSignals,
) -> Result<shell::ShellOutcome> {
    let suspended = disable_raw_mode().and_then(|()| execute!(std::io::stdout(), LeaveAlternateScreen));
    let outcome = match suspended {
        Ok(()) => shell::run_shell(host_name, ssh_target, signals),
        Err(e) => shell::ShellOutcome::SpawnFailed(format!("suspending the terminal: {e}")),
    };
    enable_raw_mode().map_err(|e| AppError::Config(format!("re-enabling raw mode: {e}")))?;
    execute!(std::io::stdout(), EnterAlternateScreen).map_err(|e| AppError::Config(format!("re-entering the alternate screen: {e}")))?;
    terminal.clear().map_err(|e| AppError::Config(format!("clearing the screen: {e}")))?;
    Ok(outcome)
}
```
