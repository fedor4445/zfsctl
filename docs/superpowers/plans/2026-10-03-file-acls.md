# File ACLs (NFSv4, getfacl/setfacl) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an **ACL** sub-tab to the Datasets right pane (a third sub-tab alongside Properties and Permissions) exposing FreeBSD's native NFSv4 access control lists on a dataset's mountpoint: view every entry in evaluated order, append a new entry at the end, and remove an entry by position.

**Architecture:** A new top-level `src/acl.rs` module (sibling to `src/zfs/`, not nested inside it — it wraps a generic FreeBSD filesystem-ACL mechanism, not a ZFS command) hand-parses `getfacl -v <path>`'s confirmed-live output into a flat `Vec<AclEntry>`, and builds the `setfacl -a <position> "<entry>" <path>` / `setfacl -x <position> <path>` commands for add/remove. `DatasetDetailTab` grows a third variant (`Acl`), turning the existing `'['`/`']'` 2-way toggle into a real 3-way cycle. The ACL path is the selected dataset's `mountpoint` field (already tracked), not its name — if `None` (a zvol, or an unmounted filesystem), the tab shows a hint instead of fetching.

**Tech Stack:** Rust (2021 edition), ratatui 0.29, crossterm 0.28 — no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-03-file-acls-design.md`.

## Global Constraints

- This crate has **no `[lib]` target** (bin-only, confirmed via `Cargo.toml`) — every test-running command in this plan is plain `cargo test ...`, never `cargo test --lib ...` (that flag errors with "no library targets found").
- **Register `mod acl;` in `src/main.rs` immediately, in the same step that creates `src/acl.rs`'s skeleton** — not deferred to a later step. An unregistered module is invisible to the compiler, so an intermediate test run against it wouldn't produce a real compile error, just "0 tests found" — defeating the RED step's purpose.
- FreeBSD only, CLI shelling via machine-readable-as-possible flags (`getfacl -v` is the closest thing NFSv4 ACLs have to one — confirmed no stricter machine-readable mode exists).
- `src/acl.rs` reuses `crate::zfs::run_checked` (declared `pub(crate)`, reachable from any module in the crate) rather than duplicating the success/failure-check boilerplate — same convention every `zfs::*` module already follows.
- No new `--`-guard convention needed here: `getfacl`/`setfacl`'s path argument always comes from an already-known dataset's `mountpoint` field (never freely typed), and the only other caller-supplied strings (a user/group name in `Recipient`, comma-separated permission/flag lists) are validated structurally by `build_pending_action` before ever reaching a command — the same "no fix needed, nothing untrusted reaches the CLI unvalidated" situation `zfs::permission` already established, not a new case to solve.
- `Permissions` is a **required** field in the new form (no sensible blank default — reuses `parse_required_perms_field`, already defined in `src/ui/state.rs` for the Permissions sub-tab, verbatim — do not write a second copy). `Flags` is genuinely optional (blank means no inheritance flags, a real common case). `Type` has a default for blank (`allow`) but is otherwise strict — only `allow`/`deny` accepted, same footgun-avoidance reasoning as Permissions' `Scope` field.
- New entries are always appended (`position = current entry count`) — no position field in the create form. Removal reads its position directly from the selected row's index in the displayed list (`getfacl`'s display order **is** the position order, confirmed via `setfacl(1)`: "NFSv4 ACL entries are evaluated in their visible order").

## Review Focus

- Pressing `'n'`/`'d'` in the `Acl` sub-tab with no dataset selected, or `'d'` with no row selected, must not panic or open a form/modal — every existing creation/removal key in this app already guards this.
- A dataset with `mountpoint: None` (a zvol, or an unmounted filesystem) must show a hint in the `Acl` sub-tab instead of attempting a `getfacl` call — this is the one genuinely new edge case this feature introduces that the Permissions/Properties sub-tabs never had to handle (they operate on the dataset name, which is never `None`).
- The `'['`/`']'` keys must correctly cycle through all **three** tabs now (Properties → Permissions → Acl → Properties), not just toggle between two — the existing 2-arm match needs real cycle logic, not just an extra arm bolted on; test both directions.
- A malformed or unrecognized `getfacl -v` line must be silently skipped, not panic or corrupt other already-parsed entries — mirrors `zfs::share::parse_shares`'s and `zfs::permission::parse_permissions`'s established leniency for the same reason.
- Switching away from the `Acl` tab's dataset via a Datasets-list refresh that re-points the selected index at a different dataset must clear the stale ACL entries — the exact same staleness-guard class that was *missing* for `dataset_permissions_for` until the Permissions feature's final review caught it; this plan builds it in from the start instead of needing a second review pass to find it.

```rust
fn split_slash_list(s: &str) -> Vec<String> {
    s.split('/').map(|p| p.trim().to_string()).filter(|p| !p.is_empty()).collect()
}

fn parse_acl_tag(tag: &str, qualifier: Option<&str>) -> Option<AclTag> {
    match (tag, qualifier) {
        ("owner@", None) => Some(AclTag::Owner),
        ("group@", None) => Some(AclTag::OwningGroup),
        ("everyone@", None) => Some(AclTag::Everyone),
        ("user", Some(name)) if !name.is_empty() => Some(AclTag::User(name.to_string())),
        ("group", Some(name)) if !name.is_empty() => Some(AclTag::NamedGroup(name.to_string())),
        _ => None,
    }
}

/// Parses one `getfacl -v` entry line (not a `#`-comment header line) —
/// confirmed live, 4 colon-separated fields for `owner@`/`group@`/
/// `everyone@` (no qualifier) or 5 fields for `user`/`group` (with a
/// qualifier): tag[:qualifier]:permissions:flags:type. Permissions and
/// flags are `/`-joined long-form names (confirmed live via `-v`); an
/// empty flags field is two adjacent colons. Returns `None` for
/// anything unrecognized, so the caller can skip a line it doesn't
/// understand instead of panicking.
fn parse_acl_line(line: &str) -> Option<AclEntry> {
    let fields: Vec<&str> = line.trim().split(':').collect();
    let (tag, perms_field, flags_field, type_field) = match fields.as_slice() {
        [tag, perms, flags, ty] => (parse_acl_tag(tag, None)?, *perms, *flags, *ty),
        [tag, qualifier, perms, flags, ty] => (parse_acl_tag(tag, Some(qualifier))?, *perms, *flags, *ty),
        _ => return None,
    };
    let entry_type = match type_field {
        "allow" => AclEntryType::Allow,
        "deny" => AclEntryType::Deny,
        _ => return None,
    };
    Some(AclEntry { tag, permissions: split_slash_list(perms_field), flags: split_slash_list(flags_field), entry_type })
}

/// Runs `getfacl -v <path>` (the `-v` flag is essential — confirmed
/// live it renders permissions/flags as named, `/`-separated long-form
/// tokens rather than the non-verbose form's undocumented fixed-width
/// positional letter codes) and parses every non-header, non-blank
/// line. Lenient: an unrecognized or malformed line is skipped rather
/// than failing the whole list, matching `zfs::share::parse_shares`'s
/// and `zfs::permission::parse_permissions`'s established leniency.
pub fn list_acl(runner: &dyn CommandRunner, path: &str) -> Result<Vec<AclEntry>> {
    let output = crate::zfs::run_checked(runner, "getfacl", &["-v", path], &format!("getfacl -v {path}"))?;
    Ok(output
        .stdout
        .lines()
        .filter(|line| !line.trim().is_empty() && !line.trim_start().starts_with('#'))
        .filter_map(parse_acl_line)
        .collect())
}
```

```rust
fn render_acl_entry(entry: &AclEntry) -> String {
    let tag_str = match &entry.tag {
        AclTag::Owner => "owner@".to_string(),
        AclTag::OwningGroup => "group@".to_string(),
        AclTag::Everyone => "everyone@".to_string(),
        AclTag::User(name) => format!("user:{name}"),
        AclTag::NamedGroup(name) => format!("group:{name}"),
    };
    let type_str = match entry.entry_type {
        AclEntryType::Allow => "allow",
        AclEntryType::Deny => "deny",
    };
    format!("{tag_str}:{}:{}:{type_str}", entry.permissions.join("/"), entry.flags.join("/"))
}

/// Inserts `entry` at `position` (confirmed live: `setfacl -a
/// <position> "<entry>" <path>`, then `getfacl -v` read back the exact
/// same entry string unchanged, including flags and `deny`).
pub fn add_acl_entry(runner: &dyn CommandRunner, path: &str, position: usize, entry: &AclEntry) -> Result<()> {
    let position_str = position.to_string();
    let entry_str = render_acl_entry(entry);
    crate::zfs::run_checked(runner, "setfacl", &["-a", &position_str, &entry_str, path], &format!("setfacl -a {position} ... {path}"))?;
    Ok(())
}

/// Removes the entry at `position` (confirmed live: `setfacl -x
/// <position> <path>` removed exactly that entry, leaving every other
/// entry's position and content untouched).
pub fn remove_acl_entry(runner: &dyn CommandRunner, path: &str, position: usize) -> Result<()> {
    let position_str = position.to_string();
    crate::zfs::run_checked(runner, "setfacl", &["-x", &position_str, path], &format!("setfacl -x {position} {path}"))?;
    Ok(())
}
```

```rust
fn draw_dataset_acl(f: &mut Frame, app: &mut App, area: Rect) {
    let dataset = app.selected_dataset_name().unwrap_or_else(|| "?".to_string());
    if app.selected_dataset_mountpoint().is_none() {
        let title = format!("ACL — {dataset} (no mountpoint -- not applicable, e.g. a zvol)");
        let table = Table::new(std::iter::empty::<Row>(), [Constraint::Min(1)])
            .block(Block::default().borders(Borders::ALL).title(title));
        f.render_widget(table, area);
        return;
    }
    let rows = app.acl_entries.iter().enumerate().map(|(i, entry)| {
        let target = match &entry.tag {
            crate::acl::AclTag::Owner => "owner@".to_string(),
            crate::acl::AclTag::OwningGroup => "group@".to_string(),
            crate::acl::AclTag::Everyone => "everyone@".to_string(),
            crate::acl::AclTag::User(name) => format!("user {name}"),
            crate::acl::AclTag::NamedGroup(name) => format!("group {name}"),
        };
        let flags = if entry.flags.is_empty() { "—".to_string() } else { entry.flags.join("/") };
        let entry_type = match entry.entry_type {
            crate::acl::AclEntryType::Allow => "Allow",
            crate::acl::AclEntryType::Deny => "Deny",
        };
        Row::new(vec![i.to_string(), target, entry.permissions.join("/"), flags, entry_type.to_string()])
    });
    let widths = [Constraint::Length(3), Constraint::Length(14), Constraint::Min(20), Constraint::Length(16), Constraint::Length(6)];
    let title = format!("ACL — {dataset} ('r' refresh, 'n' add, 'd' remove, '['/']' tabs, ← back)");
    let table = Table::new(rows, widths)
        .header(Row::new(vec!["#", "Target", "Permissions", "Flags", "Type"]))
        .block(Block::default().borders(Borders::ALL).title(title))
        .row_highlight_style(Style::default().add_modifier(Modifier::REVERSED));
    f.render_stateful_widget(table, area, &mut app.acl_entries_table);
}
```

```rust
/// Parses the ACL `Recipient` field's mini-language: `owner`, `group`,
/// `everyone`, `user:<name>`, or `group:<name>` — five shapes (one more
/// than the Permissions sub-tab's three, since ACLs distinguish the
/// owning group `group@` from a specific named group).
fn parse_acl_recipient_field(s: &str) -> Option<crate::acl::AclTag> {
    let s = s.trim();
    if s.eq_ignore_ascii_case("owner") {
        return Some(crate::acl::AclTag::Owner);
    }
    if s.eq_ignore_ascii_case("group") {
        return Some(crate::acl::AclTag::OwningGroup);
    }
    if s.eq_ignore_ascii_case("everyone") {
        return Some(crate::acl::AclTag::Everyone);
    }
    if let Some(name) = s.strip_prefix("user:") {
        if !name.is_empty() {
            return Some(crate::acl::AclTag::User(name.to_string()));
        }
        return None;
    }
    if let Some(name) = s.strip_prefix("group:") {
        if !name.is_empty() {
            return Some(crate::acl::AclTag::NamedGroup(name.to_string()));
        }
        return None;
    }
    None
}

/// Parses the ACL `Type` field — blank defaults to `Allow` (the more
/// common case), anything else must be exactly `allow`/`deny`
/// (case-insensitive). Deliberately strict, same reasoning as
/// Permissions' `Scope` field: silently defaulting a typo to the
/// *less restrictive* `allow` would be a real footgun.
fn parse_acl_type_field(s: &str) -> Option<crate::acl::AclEntryType> {
    let s = s.trim();
    if s.is_empty() || s.eq_ignore_ascii_case("allow") {
        return Some(crate::acl::AclEntryType::Allow);
    }
    if s.eq_ignore_ascii_case("deny") {
        return Some(crate::acl::AclEntryType::Deny);
    }
    None
}

/// Parses an optional comma-separated `Flags` field — splits, trims,
/// drops empty tokens; blank (or just commas/whitespace) is valid and
/// means no inheritance flags, unlike the required `Permissions` field.
fn parse_optional_flags_field(s: &str) -> Vec<String> {
    s.split(',').map(|p| p.trim().to_string()).filter(|p| !p.is_empty()).collect()
}
```
